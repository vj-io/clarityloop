## Before recording

1. Open `/judge` → "Open both side by side". Wait for the green "live" chip in both windows.
2. If the chat is not empty, wait 20 idle minutes or ask for a reset (the sandbox clears itself).
3. Run the six lines once as a rehearsal, then reset and record.
4. Upload to YouTube (unlisted) or Loom; make sure anyone with the link can watch. Paste the link in the form.
