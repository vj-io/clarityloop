## Sections

1. **The problem.** A building site at the start of a shift. An instruction is translated and read, the worker replies OK, and the cement goes to the wrong gate. Read is not understood.
2. **The idea.** No OK button. The worker says the task back; AI only reads the reply into fields; plain code compares; Confirm stays blocked until both agree.
3. **How it is built.** Nexconn Chat SDK group channels with read receipts, unread counts and mentions; cards posted by the server; Next.js on Vercel; Supabase.
4. **The demo.** Chat in your own language; the task "40 bags, Gate 3, 2 p.m."; Murugan names Gate 2 and the red card catches it in both windows; fixed in the same chat; Understood.
5. **Whole crew.** One task in Hindi and Tamil; Ravi's roll call shows which field went wrong; Lakshmi only sees that Murugan has not got it yet.
6. **Safety briefing.** Work at height: three of four points said, the harness is asked for again, then every point is understood.
7. **Close.** Voice in and out, task record. Runs today in a sandbox with demo accounts; no pilot has run yet; an extra check, not a safety guarantee. Team credit and App Key `qd46yzrfq1obf`.
